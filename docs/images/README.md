# 展示图片来源

本目录四张 PNG 均原样提取自项目原有 Word《项目测试报告》（视域经纬，2025 年项目材料），没有重新生成、修改预测数据或重新绘制界面。

- `single-prediction.png`：Word 内 `word/media/image3.png`，单图检测结果。
- `deepseek-analysis.png`：Word 内 `word/media/image4.png`，DeepSeek 分析展示。
- `batch-prediction.png`：Word 内 `word/media/image5.png`，批量检测展示。
- `history.png`：Word 内 `word/media/image8.png`，历史记录展示。

截图中的影像、分数与分析文本属于历史演示内容，不能替代独立评测或临床结论。Word 原文档不随本次 README 更新公开上传。
